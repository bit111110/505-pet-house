# V5.9.9 綜合操作改善版

包含老師指定的 8 項更新：

1. 老師後台密碼改成遮罩輸入（type=password）。
2. 每位學生金幣改成自由輸入金額後一次發放。
3. 老師後台新增勾選學生＋批量發道具。
4. 題目、選項、解析中的 `1/2` 自動顯示成上下分數。
5. 「更新遊戲設定」按完會保留成功時間並跳出成功提示，不再像沒反應。
6. 小屋寵物可直接拖曳；天空型可放整張地圖，地面型拖到天空會自動掉回地面。
7. 移除小屋管理中的「切換到對戰畫面」按鈕。
8. 升級頁新增勾選多種 EXP 道具後批量使用；每個道具也有「全部」快捷鍵。

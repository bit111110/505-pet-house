## 必做：Apps Script
把 `apps-script/Code.gs` 覆蓋後：
1. 執行一次 `setupOrUpgradeV55()`。
2. Apps Script → 專案設定 → 指令碼屬性，新增：
   - 屬性：`ADMIN_PASSWORD`
   - 值：`10727101`
3. 重新部署網頁應用程式「新版本」。

> 不要把老師密碼直接寫進 GitHub。你的 repository 是公開時，任何寫在前端或公開 Code.gs 的密碼都能被看到。

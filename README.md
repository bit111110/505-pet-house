# V5.6.4 強制即時背景分類版

這版不再猜，也不再使用舊快取判斷背景分類。

每次打開「土地／背景」：
1. 先顯示「正在同步最新背景設定...」
2. 直接向 Apps Script 讀取 Google 試算表「土地設定」
3. 讀完才產生金幣 / 寶物兩區

另外：
- 只要兌換道具ID有值，而且兌換數量 > 0，就強制視為「寶物」背景。
- 即使「取得方式」因舊快取錯誤變成金幣，也不會把 LAND009 / LAND010 放進金幣區。
- 後端同時回傳英文鍵與中文鍵，避免欄位映射再被吃掉。
- 如果 Apps Script 還是舊部署，畫面會直接顯示「背景設定同步失敗」，不會偷偷退回錯誤的舊資料。

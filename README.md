# V5.6.3 寶物背景分類修正版

你截圖中的設定其實是正確的：

LAND009 / LAND010：
- 取得方式 = 寶物
- 兌換道具ID = TRE001
- 兌換數量 = 100

問題出在前端：Apps Script 已經把 `取得方式 / 兌換道具ID / 兌換數量`
傳回來，但舊版 `getLandShopRows()` 又把這三個欄位丟掉了。

所以網站最後只看到：
- 名稱
- 價格
- 圖片

結果 LAND009 / LAND010 被誤判成「金幣背景 + 價格空白」，
因此出現在金幣區並顯示「尚未設定金幣價格」，
寶物兌換區則顯示沒有背景。

V5.6.3 已修正：
- 保留取得方式
- 保留兌換道具ID
- 保留兌換數量
- 保留兌換道具名稱
- 金幣 / 寶物背景會正確分區

# V5.10.1 教室多人效能版

這版針對「全班同時使用時一直 Loading」調整連線時機。

## 主要改動

1. 寵物自動走動不再寫 Google Sheet
- 自動走動只發生在學生自己的瀏覽器。
- 不再每 20 多秒全班一起存位置。
- 只有學生手動拖曳寵物、放手時才存一次真正位置。

2. 登入後不再預載五科完整題庫
- 登入：只拿小屋核心資料與背包。
- 點「對戰」：只拿五科的題目數量 + 今日挑戰狀態。
- 點某一科：才下載那一科完整題庫。
- 同一台裝置已抓過的科目題庫會存在瀏覽器 1 小時。

3. 信箱取消定時輪詢
- 不再登入 45 秒後、每 5 分鐘全班一起更新信箱。
- 學生點進「信箱」才讀。
- 有本機快取時先直接顯示，按「更新信箱」才抓最新。

4. 答題同步更安靜
- 一般答題同步改成背景 gsRaw，不顯示整頁 Loading。
- 累積 12 題再批次同步一次。
- 錯 3 題、結束戰鬥等重要節點仍會強制同步。

5. 題庫科目灰色功能保留
- 對戰首頁只抓題目數量。
- 0 題的科目維持灰色「暫無題目」。

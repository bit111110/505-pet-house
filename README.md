# V5.10.4 小更新版

本版只處理這 4 件事：

1. **25 個學生帳號固定在 Code.gs**
   - 登入時不再掃描「學生資料」工作表找帳號/生日。
   - 固定名單位置：`STATIC_STUDENT_LOGIN_V5104`
   - 日後若要修改學生帳號或生日，直接改這個物件即可。
   - 學生的金幣、寵物、土地等遊戲資料仍照常從 Google Sheet 讀取，不會重設任何資料。

2. **登入後圖片載入顯示「圖片載入中...」**
   - 小屋資料回來後，等待目前小屋的背景與寵物圖片完成載入。
   - 最長等待 7 秒，圖片失敗也不會永久卡住。

3. **經驗糖果防連點 / 防卡死**
   - 一次使用尚未完成時，所有經驗糖果按鈕與數量欄位會暫時鎖定。
   - 後端加入 Script Lock，避免雙擊造成兩支請求同時扣道具/加經驗。
   - 成功或失敗後都會自動恢復按鈕。

4. **挑戰首頁加速**
   - 進「挑戰」時不再先掃描五科題庫，也不再顯示「檢查題庫中…」。
   - 五科按鈕立即出現。
   - 只有真正點某一科時才下載那一科題庫。
   - 題庫瀏覽器快取由 1 小時延長為 6 小時。
   - 今日挑戰狀態改成登入後背景一次載入。

## 更新方式

GitHub：
- `app.js`
- `index.html`

Apps Script：
- `apps-script/Code.gs`

Apps Script 儲存後執行一次：

`setupOrUpgradeV5104()`

然後重新部署 Web App 新版本。

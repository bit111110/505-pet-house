# V5.10.5 對戰存檔版

新增「💾 儲存並離開」。

## 行為
- 對戰中的答題紀錄會先同步。
- 再儲存：
  - 科目
  - 出戰寵物
  - 怪物編號
  - 怪物目前 HP
  - 怪物最大 HP
  - 最近已出過的題目
- 下次進入同一科目時，如果有存檔，會看到：
  - ▶️ 繼續對戰
  - 🔄 重新開始
- 重新開始只刪除怪物進度，不會刪除當天已答對／答錯的紀錄。
- 「結束對戰」現在會先提醒：若沒有按儲存，本隻怪物的進度不會保存。

## 新增工作表
執行 setupOrUpgradeV5105() 後會自動建立：
`對戰存檔`

欄位：
學號｜科目｜寵物ID｜怪物編號｜怪物HP｜怪物最大HP｜已看題目｜最後更新

不會刪除或重設任何既有學生資料。
